Resource ID of the model directory. example:aircraft loads assets/example/eca/blender/aircraft/definition.json and the .blend or .glb file selected by its model field. The default filename is model.glb; for a native Blender file, explicitly set "model": "model.blend". An ID without a namespace uses this workspace's mod ID. This is Blender support's only resource layout; there is no legacy directory fallback.
