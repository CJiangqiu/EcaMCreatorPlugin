Mark this entity as the wave's leader instead of an ordinary spawn entry; count is ignored because a leader is always a single entity. A wave has at most one leader — if several rows in the same wave are marked, the last one wins. Requires a Raider Faction to be set: the leader is made the leader of that faction, which is what makes every raider answer when it attacks or is attacked. Without a faction the entity is spawned as an ordinary raider instead.
